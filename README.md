# biologia_computacional_5458
Este repositorio funciona como una base de datos del historial de versiones del código generado en clase

Reglas de calidad de datos
Incluye estas reglas explícitamente en el README.md:

Usar fechas ISO: AAAA-MM-DD; por ejemplo, 2026-09-12.

No usar comas dentro de los campos de texto; si son necesarias, encerrar el texto entre comillas.

Registrar una sola práctica por fila.

Si una persona tiene varias prácticas, debe añadir más filas.

Usar valores controlados para estado: por_confirmar, confirmada, cancelada.

No incluir datos sensibles ni coordenadas precisas.

La estandarización es el punto pedagógico central: la automatización no “arregla” datos ambiguos; depende de que el equipo acuerde un esquema antes de comenzar a capturar.
